# Проект: IMDb Explorer (Анализ данных из топ-1000 фильмов по версии IMDb)

Этот проект представляет собой комплексный анализ данных о 1000 лучших фильмах по версии IMDb. Основная цель — продемонстрировать полный цикл работы с данными: от загрузки и очистки до глубокого анализа и визуализации результатов.

## 🚀 Ключевые Возможности

*   **Аудит Качества Данных:** Глубокая проверка на наличие дубликатов и пропущенных значений для обеспечения надежности анализа.
*   **Целевой Анализ:** Способность извлекать из общего набора данных конкретные срезы по заданным параметрам (на примере карьеры актера Уиллема Дефо).
*   **Проверка Статистических Гипотез:** Расчет коэффициента корреляции Пирсона для проверки связи между оценками критиков и зрителей.
*   **Наглядная Визуализация:** Построение диаграммы рассеяния с помощью Matplotlib для визуального подтверждения статистических выводов.

## 🖇️ Разработка с ИИ-ассистентом

Проект реализован в тесном сотрудничестве с продвинутым ИИ-ассистентом (Gemini). Этот подход был выбран сознательно, чтобы продемонстрировать современный рабочий процесс, в котором специалист выступает в роли ведущего аналитика, а ИИ — в роли мощного инструмента для генерации кода, объяснения сложных концепций и совместного дебаггинга.

*   **Роль аналитика (человека):** Постановка задач, формулирование гипотез, проверка и отладка кода, интерпретация результатов и принятие финальных решений.
*   **Роль ИИ-ассистента:** Генерация кода по запросу, пошаговое объяснение синтаксиса и концепций, предложение альтернативных решений и помощь в поиске и устранении ошибок.

## 📊 Анализ и Результаты

### Этап 1: Аудит и проверка качества данных
Любой серьезный анализ начинается с проверки целостности данных.

*   **Дубликаты:** Анализ выявил два фильма с одинаковым названием `Drishyam`. Расследование показало, что это не ошибка, а оригинал (2013) и ремейк (2015). Удаление не потребовалось.
*   **Пропущенные значения:** Обнаружены пропуски в колонках `Certificate` (101), `Meta_score` (157) и `Gross` (169), что было учтено на последующих этапах.

**Вывод:** Для разных этапов анализа будет применяться разная стратегия. Для целевого анализа (поиск актера) пропуски можно игнорировать, для корреляционного анализа строки с отсутствующими оценками будут исключены.

### Этап 2: Целевой анализ: Карьера Уиллема Дефо

### Этап 3: Проверка гипотезы и визуализация
Была проверена гипотеза: **"Существует значимая положительная корреляция между оценками критиков (`Meta_score`) и зрителей (`IMDB_Rating`)"**. Для проверки гипотезы был рассчитан коэффициент корреляции Пирсона и построена диаграмма рассеяния.

![Корреляция между оценками критиков и зрителей](rating_correlation.png)

**Результаты и выводы:**

*   **Коэффициент корреляции составил `+0.27`**, что указывает на **слабую положительную связь**.
*   **Визуализация** подтвердила общий тренд (график движется из левого нижнего угла в правый верхний), однако облако точек оказалось широким и рассеянным, что указывает на частое расхождение мнений критиков и зрителей.
